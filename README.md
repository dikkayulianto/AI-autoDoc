> **AI-autoDoc** adalah generator dokumen bukti fisik dan instrumen pemantauan pendidikan otomatis (**Jabar Beraksi : 1 Penguatan Pendidikan Karakter**) berbasis peramban web (*Client-Side Engine*). Dirancang khusus untuk membantu kepala sekolah, guru kelas, guru BK, dan tenaga kependidikan menyusun administrasi formal siap cetak dalam format **Microsoft Word (.docx)** yang 100% dapat disunting.

---

## 🔒 Gerbang Keamanan Landing Page (Private Access Gate)

Untuk menjaga agar aplikasi ini tidak diakses sembarang orang di internet, sistem dilengkapi dengan **Gerbang Kode Akses (Protected Passcode Gate)**:

* **Kode Akses Default:** `JABAR2026`
* **Mekanisme Keamanan:**
  1. Pengunjung wajib memasukkan kode akses yang valid pada tampilan gerbang awal.
  2. Status akses tersimpan otomatis pada sesi browser (`sessionStorage`).
  3. Tersedia tombol **"Kunci Portal"** pada navigasi atas untuk mengunci kembali aplikasi saat selesai digunakan.

## ⚡ Fitur Utama Aplikasi

1. **Formulir Profil Sekolah Terintegrasi**
   * Mengubah Nama Satuan Pendidikan, NPSN, Kecamatan, Alamat, Nama Kepala Sekolah, NIP, serta Pengawas Pembina.
   * Kop surat resmi, naskah isi, dan kolom tanda tangan di dokumen Word otomatis diselaraskan.

2. **Ekspor Sekali Klik: File Satuan (.docx) & Paket Lengkap (.ZIP)**
   * Unduh per berkas indikator secara individual.
   * Unduh sekaligus 12 berkas dalam 1 arsip `.ZIP` dengan penamaan file yang rapi dan terstandar.

3. **Generator Kustom dengan Google Gemini AI**
   * Buat bukti fisik untuk **Poin 1 s/d 15** atau indikator baru apa pun di luar instrumen ini.
   * Masukkan API Key Gemini gratis Anda, lalu AI akan merumuskan SOP, tabel instrumen, dan naskah berita acara secara otomatis.

4. **100% Client-Side Engine (Serverless)**
   * Dijalankan murni di peramban pengguna (*browser*) menggunakan pustaka `docx.js`, `FileSaver.js`, dan `JSZip`.
   * Cepat, tanpa ketergantungan server database, dan tidak akan mengalami *downtime*.

## 🚀 Panduan Deploy ke Vercel

Aplikasi ini siap digunakan langsung di Vercel dalam 3 langkah mudah:

1. Buka [Vercel Dashboard](https://vercel.com/dashboard) dan login menggunakan akun GitHub Anda.
2. Klik tombol **"Add New..."** > pilih **"Project"**.
3. Cari repositori **`dikkayulianto/AI-autoDoc`**, lalu klik **"Import"**.
4. Biarkan konfigurasi default (*Framework Preset: Other*), lalu klik **"Deploy"**.
5. Selesai! Web Anda langsung aktif dengan domain resmi (misal: `https://ai-auto-doc.vercel.app`).

## 💻 Cara Menjalankan Secara Lokal di Komputer

Tidak perlu koneksi internet untuk fitur preset standar:
1. Kloning repositori ini:
   ```bash
   git clone https://github.com/dikkayulianto/AI-autoDoc.git
   cd AI-autoDoc
   ```
2. Buka file `index.html` langsung dengan mengklik dua kali atau gunakan server lokal:
   ```bash
   npx serve .
   ```
3. Buka peramban di `http://localhost:3000`.
